# Парсер новостей

Telegram-бот для одного пользователя: раз в час собирает статьи с выбранных сайтов, отсеивает неинтересные темы,
склеивает пересказы одного события, ранжирует и каждое утро в 8:30 (Алматы) присылает две подборки за сутки:

- **Новости AI** — топ-10 по значимости; срочное приходит сразу (кроме ночи 23:00–8:00).
- **Боли** — 10 реальных проблем людей и бизнеса, которые можно решить с помощью ИИ (для насмотренности).
  У каждой: отрасль, как решают сейчас, как поможет ИИ, кто уже решает, сигнал массовости, применимость к Казахстану.
  Не больше двух болей из одной отрасли.

Саммари только на русском, 4–6 предложений. У каждой ленты свои источники, темы, промпт LLM и настройки.

## Как это устроено

| Файл | Что делает |
|---|---|
| `main.py` | Бот: команды, кнопки, расписание (часовой обход, сводка, очистка) |
| `pipeline.py` | Сбор → обработка LLM → ранжирование → отбор для сводки и срочных |
| `fetchers.py` | Чтение RSS/Atom, HTML-страниц, HF Daily Papers, Hacker News; поиск ленты у сайта |
| `llm.py` | DeepSeek: фильтр тем, склейка в события, оценка 1–10, саммари — одним запросом на пачку из 10 статей |
| `db.py` | SQLite: источники, статьи, события, отзывы, настройки; срок хранения 30 дней |
| `seed.py` | Стартовые источники: 20 для новостей, 9 для болей |

**Оценка события** = 1.5 × оценка LLM + вес источника (1–3) + кросс-упоминания (1.5 за каждый доп. источник, до 4.5)
+ внешние метрики (очки HN 150/300/600+, апвоуты HF 50/100/200+ → +1/+2/+3).
В сводку попадают события с оценкой LLM ≥ «мин. оценки» (по умолчанию 6) — если их меньше лимита, приходит сколько есть.

**Срочно** — событие, о котором за 3 часа написали ≥3 источника с весом 2–3 (порог в /settings).

Кнопки «Полезно / Не интересно» сохраняются в таблицу `feedback`; в ранжировании пока не участвуют.

## Особенности источников

- **Hacker News**: hnrss.org часто отвечает 502, поэтому тот же запрос идёт через API Algolia (там же очки).
- **Reddit**: JSON без браузера закрыт (403), поэтому только RSS «топ дня», без очков.
- **Meta AI Blog**: обычному браузерному User-Agent отдаёт 400; при отказе бот повторяет запрос как краулер превью ссылок.
- **Mistral**: у сайта нашлась RSS (`/news/rss`), HTML не нужен.
- **Anthropic, Meta**: разбор HTML — ссылки со страницы-списка, у новых статей бот открывает страницу и берёт заголовок, дату и текст.
- Релизы GitHub: альфы, беты и rc пропускаются.
- **Боли**: главный источник — профессиональные сабреддиты, собранные в два мультиреддита (офисные профессии:
  бухгалтеры, юристы, HR, страхование, риелторы, IT-аутсорс; бизнес «в поле»: рестораны, e-commerce, стройка, HVAC,
  стоматология, логистика, фриланс). Плюс Entrepreneur+smallbusiness, Ask HN, поиск Reddit по фразам «is there an app /
  I wish there was», SomebodyMakeThis+AppIdeas+Lightbulb, vc.ru, и с малым весом кейсы (Starter Story,
  SideProject+SaaS+microsaas+indiehackers) — боль, которую уже закрыли продуктом. Шума много — его отсеивает LLM.
- До 2026-10-23 вместо «Болей» была лента «Бизнес-идеи»; её источники при запуске переходят в «Боли» или выключаются
  (`seed.ensure`). Не подходили и для неё: There's An AI For That и Indie Hackers (403), YC Launches и Astana Hub (JS).
- У HTML-источника можно задать `link_prefix` — путь, под которым лежат статьи, если он не совпадает со страницей-списком
  (Starter Story: главная → `/stories/`).

## Запуск

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # BOT_TOKEN, OWNER_ID, LLM_API_KEY
python main.py
```

Для постоянной работы есть пример сервиса systemd: `news-parser.service`. Сейчас проект нигде не развёрнут.
